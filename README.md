# TVBox 点播源模板

这是一个适用于电影、电视剧、综艺和动漫的 TVBox JSON 配置模板。仓库目前没有提供影视 API 或内容授权信息，因此 `tvbox.json` 中的 `https://example.com/api.php/provide/vod/` 仍是占位地址，不能直接使用或播放。

## 配置

1. 将 `tvbox.json` 中的 `api` 替换为你拥有使用权的点播 API 地址。
2. 确认该接口提供 TVBox/苹果 CMS 兼容的 JSON VOD API，并且接口中包含电影、电视剧、综艺、动漫分类；分类名称以 API 实际返回为准。
3. 如果接口需要特殊参数、分类映射或自定义解析配置，请按该服务的文档调整配置。
4. 将 `tvbox.json` 托管到你自己的 HTTPS 静态站点，并在 TVBox 中添加该文件的链接。
5. 只接入你拥有或获准分发的内容与接口。

提供已获授权的 API 地址及其接口类型后，可以继续适配配置。
